# DropWatch

**Haojia Dang** · MGMT 6110 Human-AI Collaboration · Problem Set 1

A two-screen front end for concert-ticket fans: follow artists, see which
platform each on-sale is happening on and when, get reminded the day before,
confirm, and watch a live countdown on the day.

External users. All data is invented. The app calls no model and no outside
service, and sends no notifications.
